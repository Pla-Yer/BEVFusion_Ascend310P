### Analysis

1. **融合模型性能问题**：
   - 融合推理耗时高达1427ms，远超LiDAR单独推理的102ms
   - 主要瓶颈在于数据拷入/拷出操作频繁

2. **bev_pool性能瓶颈**：
   - bev_pool单独作为OM模型推理耗时达1300ms
   - bev_pool主要计算是将特征撒在BEV网格中，这种计算NPU不擅长

3. **精度对比**：
   - LiDAR单独：mAP=0.2186
   - 融合模型：mAP=0.217
   - 融合后精度略有下降，可能需要进一步调优
