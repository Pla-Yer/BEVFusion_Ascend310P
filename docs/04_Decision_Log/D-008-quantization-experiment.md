# D-008: 模型量化实验决策

**日期**: 2026-03-30
**状态**: ✅ 已完成
**决策者**: 项目组

## 背景

在完成端到端性能优化后，FPS达到6.01，为进一步提升性能和减少模型大小，需要探索模型量化方案。AMCT（Ascend Model Compression Toolkit）提供了针对昇腾芯片的量化工具，支持训练后量化（PTQ）。

## 决策内容

### 量化策略选择

**选择方案**: 使用AMCT进行ONNX模型训练后量化（PTQ）

**理由**:
1. ONNX是最广泛使用的IR，适配性好
2. 项目模型转换路径为 pth→onnx→om，有先验经验
3. AMCT针对昇腾芯片优化，能获得更好的性能收益
4. PTQ不需要重新训练，实施成本低

### 量化配置

**量化方法**: 均匀量化（Uniform Quantization）
**量化位宽**: INT8
**量化对象**: 权重（Weight）+ 激活（Activation）

**校准策略**: IFMR（Input Feature Map Range）

### 分支量化结果

| 分支 | 原始大小 | 量化后大小 | 压缩率 | 原始延迟 | 量化延迟 | 原始精度 | 量化精度 | 结论 |
| ---- | -------- | ---------- | ------ | -------- | -------- | -------- | -------- | ---- |
| Camera | 100MB | 27MB | 73% | 55ms | 45ms | - | - | ✅ 成功 |
| LiDAR | 133MB | 132MB | 0.75% | - | - | 0.21 | 0.17 | ❌ 失败 |
| Fusion | 25MB | 9MB | 64% | 45ms | 50ms | 0.21 | 0.12 | ❌ 失败 |

## 失败根因分析

### LiDAR分支失败原因

1. **动态轴导致IFMR校准失效**
   - VFE输入第0维是voxel数量V，每帧不同（3000~12000）
   - 校准在固定max_voxels=10000上进行
   - 实际推理时V变化，导致scale和offset不准确

2. **无可压缩的大型参数**
   - LiDAR分支只有PillarVFE（3个Linear层）和Scatter操作
   - Scatter不在AMCT支持层列表中
   - 真正的大型参数（SECOND骨干、SecFPN）在Fusion Head中

### Fusion分支失败原因

1. **精度暴跌根因**
   - SECOND骨干和SecFPN被量化为INT8
   - 量化误差通过BEV特征传递到Decoder的cross-attention
   - Attention对输入精度敏感，误差被softmax指数放大
   - **量化了不该量化的上游特征**

2. **延迟反增根因**
   - 跳过Decoder后产生大量INT8/FP16混合精度边界
   - 每个边界需要插入AscendQuant/AscendDequant算子
   - 精度转换开销超过INT8推理节省的计算量

3. **结构不匹配**
   - Fusion Head瓶颈在Transformer Decoder（双变量MatMul）
   - 双变量MatMul在310P上量化无收益
   - 跳过瓶颈部分，却保留了精度边界惩罚

## 后续决策

### Camera分支
- ✅ 继续使用量化模型
- 探索更低位宽（INT4）量化可能性

### LiDAR分支
- ❌ 不单独量化LiDAR分支
- ✅ 将LiDAR骨干网络（在Fusion Head中）整体量化

### Fusion分支
提供三个可选方案：

**方案A**: 全量化，接受精度损失（0.21→0.12）
- 优点：模型最小（9MB），部署简单
- 缺点：精度损失严重，不可接受

**方案B**: 只量化骨干+跳过Decoder，接受延迟不变
- 优点：精度保持，模型较小
- 缺点：延迟不降反升（45ms→50ms）

**方案C**: 探索QAT（量化感知训练）
- 优点：可能获得更好的精度-性能平衡
- 缺点：需要重新训练，成本高

**推荐**: 方案C，但优先级较低，先完成其他优化

## 影响评估

### 正面影响
- Camera分支成功量化，模型大小减少73%，延迟减少18%
- 积累了量化经验和失败案例分析
- 识别了不同网络结构对量化的适应性差异

### 负面影响
- LiDAR和Fusion分支量化失败，需要重新设计策略
- 投入时间进行量化实验，但未获得预期收益

## 经验总结

1. **量化成功的关键是硬件适配和网络结构匹配**
2. **动态shape网络需要特殊处理校准数据**
3. **混合精度边界的开销不可忽视**
4. **上游特征量化误差会在敏感模块中被放大**
5. **不是所有网络结构都适合量化，需要具体分析**
