# Risk Register

This directory records project risks and their management strategies for the BEVFusion-Ascend310P deployment project.

The goal is to document:

- Technical risks
- Schedule risks
- Resource risks
- External risks
- Risk mitigation strategies

Each risk record contains:

- Risk level and impact
- Probability assessment
- Description and context
- Mitigation strategy
- Contingency plan
- Status tracking

These records serve as an internal engineering reference and risk management knowledge base.

For risk reporting, please use the following template and add an index to Index.md:

## Risk Template

```markdown
## R-XXX: [Risk Title]

### Level
High / Medium / Low

### Impact
[Describe impact]

### Probability
High / Medium / Low

### Description
[Detailed description]

### Mitigation Strategy
1. [Strategy 1]
2. [Strategy 2]

### Contingency Plan
- [Plan if risk materializes]

### Status
⏸️ Monitoring / 🔄 Mitigating / ✅ Resolved

### Last Update
YYYY-MM-DD
```
